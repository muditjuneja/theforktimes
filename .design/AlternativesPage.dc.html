Open source substitutes for Notion A substitution is listed when the project genuinely replaces Notion for a real use case — not merely because their feature lists overlap. Three entries
I
toeverything/affine Local-first workspace storing data on disk with CRDT sync, combining a document editor, whiteboard canvas and databases in one block-based interface. Productivity  ·  Not yet measured — has not appeared in an edition
II
outline/outline Real-time collaborative wiki storing documents as markdown over Postgres, shipped as a Docker image for self-hosting. Productivity  ·  Not yet measured — has not appeared in an edition
III
appflowy-io/appflowy Rust core with a Flutter UI, so the same codebase runs desktop, mobile and web clients against a self-hosted sync server. Productivity  ·  Not yet measured — has not appeared in an edition
How this list is made Notion is a commercial product, so “what replaces it” is a question with a real answer. Every substitution here is a curated editorial claim, not a topic match: the table it comes from is maintained by hand. Projects are ranked by stars per day since launch, the fallback used until a project has two snapshots a week apart. Projects marked unmeasured are claims we stand behind but have not yet put a number to, because they have not appeared in an edition.
